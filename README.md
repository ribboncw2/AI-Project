# Ontario dual-audience report dashboard

A simple local website for one professional report with two readers: your **principal** (classroom and school) and the **board** (program and system). You do not need to code.

This GitHub copy is the **dashboard only**. Files you add on Uploads stay on your computer and are not sent to GitHub.

## How to start (once)

1. Open the **AI-Project** folder.
2. Double-click **start.command** (or, in Terminal: `python3 server.py`).
3. In your browser, go to **http://localhost:8080**

If macOS asks whether to open the file, choose Open. Leave the small Terminal window open while you use the dashboard.

## Everyday use

1. Open **http://localhost:8080**
2. On **Uploads**, add files you downloaded from Google Drive (or drop them into the `uploads` folder in this project).
3. In Cursor chat, say what to add, change, or rephrase. Preview **Principal**, **Board**, or **Full**, then use **Print** and choose Save as PDF.

## Privacy

Student names, marks, IEPs, and photos must stay on this computer. Do not paste them into a public GitHub page.
